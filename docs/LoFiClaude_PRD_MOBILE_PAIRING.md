# LoFiClaude 手机配对 PRD 补充

## 用户故事

用户在电脑打开 LoFiClaude 后，希望离开电脑前仍能用手机查看 Claude 对话、发送消息、切换场景和控制电脑音乐，但音频和 Claude 运行仍留在电脑本机。

## 核心流程

```text
电脑端开启手机连接 → 显示二维码 → 手机扫码
→ 手机进入当前房间 → 查看状态/继续对话/控制电脑播放
→ 断开手机或关闭电脑端连接
```

## 功能需求

| ID | 需求 | 优先级 | 验收 |
|---|---|---|---|
| MP-01 | 电脑端主动开启手机连接 | P0 | 默认不暴露局域网，点击后才开启 |
| MP-02 | 显示二维码和过期倒计时 | P0 | 5 分钟过期，过期后扫码失败 |
| MP-03 | 手机扫码进入当前房间 | P0 | 无需复制 token |
| MP-04 | 手机查看当前场景、Clawd、音乐、雨声和计时 | P0 | 首屏收到完整 room_state |
| MP-05 | 手机和电脑共享 Claude 对话 | P1 | 两端实时收到 user、delta、done/error |
| MP-06 | 手机控制电脑音乐和雨声 | P1 | 只调用白名单命令，状态以电脑实际回读为准 |
| MP-07 | 断线重连和事件补发 | P1 | 不重复消息、不丢失终态 |
| MP-08 | 电脑撤销手机连接 | P1 | 撤销后手机立即失去控制权 |
| MP-09 | 移动端适配 | P2 | 375×812 和真实手机无横向滚动 |

## 非目标

- 手机本地播放电脑的网易云或 YouTube 音频。
- 手机单独启动 Claude CLI。
- 云端账号、远程公网访问、多用户和社交功能。

## 产品状态文案

- `等待扫码`
- `手机已连接`
- `配对已过期`
- `电脑连接中断`
- `电脑正在播放：{title}`
- `Claude 正在回复`
- `手机控制已撤销`

## 指标

手机配对不是独立增长目标，服务于有效专注 Session：

- 配对成功率
- 扫码后 10 秒内状态可见率
- 手机消息完成率
- 手机控制命令真实执行率
- 多端状态不一致率
- 配对断线恢复率

北极星指标仍是“每周完成的有效陪伴专注 Session 数”，不增加社交指标。

## 风险与限制

- 局域网隔离、访客 Wi-Fi 或系统防火墙可能阻止手机连接。
- iOS Safari、Android Chrome 的自动播放策略不影响本方案，因为音频只在电脑播放。
- 用户离开局域网后连接会断开；首版不提供公网穿透。
- 二维码页面不得记录 token 到分析服务或 URL 历史之外的持久存储。
