# LoFiClaude 文档索引

## 权威层级

1. `LoFiClaude_PRODUCT_DIRECTION.md`：产品定位、目标用户和长期取舍。
2. `LoFiClaude_PRD_V1.1.0.md`：当前版本的实施范围、验收标准和发布决策。
3. `ARCHITECTURE.md`：与当前代码一致的产品和系统架构。
4. 根目录 `HANDOFF.md`：当前工作状态、验证结果和下一步。

产品方向决定长期取舍；PRD 决定产品契约；`PRODUCT_PLAN_V1.2.md` 定义本轮 Phase 范围。实际完成状态、验证证据和待办以根目录 `HANDOFF.md` / `TODO.md` 为准，历史文档不能覆盖当前已确认决策。

## 归档

- `archive/prd/`：已被替代的 PRD 和历史方案，仅供追溯。
- `archive/HANDOFF_v1.0_2026-05-24.md`：V1.0 交接快照。
- `archive/tasks/`、`archive/specs/`：历史任务和工程规格。
- 根目录 `SESSION_LOG.md` 及 `archive/` 下其他材料：历史过程记录，不作为当前状态源。
- 根目录 `RELEASE_AUDIT.md`：顶部为当前决策，下方原始评分与行号是历史审计证据。

归档文档不作为当前实现依据，除非当前 PRD 明确引用。
