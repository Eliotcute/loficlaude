# 重写 Claude sprite — 基于 Claude Code logo

## 参考

Claude Code CLI 的 logo 是一个圆润橙色 blob：

```
  ▐▛███▜▌     ← 圆头顶 + 两侧耳朵
▝▜█████▛▘    ← 宽身体（更宽）
  ▘▘ ▝▝      ← 两只小脚
```

## 规格（24x24 像素，每字符 ≈2-3 像素）

颜色：
```
1 = #df805f  (橙色身体)
2 = #141414  (黑色头发/头顶块)
3 = #0a0a0a  (眼睛、嘴巴)
4 = #f2d58e  (星星黄)
```

### 身体形状
- 主体：圆角矩形 / 椭圆，占 x:4..19, y:3..17
- 耳朵：在 y:4-6 处左右各突出 2px（像 ▐ 和 ▌）
- 头顶块（深色）：y:1-3, x:6..17
- 小脚：y:18-19, x:8..10 和 x:13..15
- 星星（黄色）：在身体右侧，x:20..22, y:5..7

### 每帧的变体

每个动画帧基于这个主体，只有以下部分变化：

- idle_1：正常睁眼（2x2 眼），正常嘴
- idle_2：眨眼（眼睛变 1px），正常嘴
- walk_1：左脚本在前，右脚本在后
- walk_2：右脚本在前，左脚本在后
- talk_1：张嘴
- talk_2：闭嘴
- sleep_1：闭眼（横线），身体略矮
- sleep_2：闭眼 + Zzz（1px 小点飘出）
- thinking_1：眼睛斜上方看，手托状
- thinking_2：换边
- working_1：眼睛专注向下，一只耳朵闪
- working_2：换边闪
- blocked_1：眼睛瞪大（3x2），嘴巴 O 形
- blocked_2：同
- happy_1：眼睛弯月形 ^ ^，星星变大
- happy_2：同，星星闪烁

**关键：不是人形，是圆润小怪物/blob，和 Claude Code logo 一致**
